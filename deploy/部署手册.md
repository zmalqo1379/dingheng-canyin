# 鼎恒餐饮 —— 正式环境部署手册

目标：让 `你的域名` 在任何电脑/手机上都能打开，供应商可自行浏览。

数据库说明（重要）：项目用的数据库本来就在云上（MongoDB Atlas），
**服务器上不用装数据库、不用导数据**，只需让服务器能连上它。

---

## 第 0 步：搞清你买的服务器是什么（10 秒）

登录腾讯云控制台 → 轻量应用服务器（或云服务器 CVM）→ 实例列表 → 点你的实例，
看清这三样并记下来：

| 要看的 | 在哪 |
|---|---|
| 公网 IP | 实例列表第一列，形如 `1.2.3.4` |
| 操作系统镜像 | 「镜像」列，形如 `Ubuntu 22.04` / `CentOS 7` / `宝塔面板 7.x` / `Windows Server` |
| 登录方式 | 轻量控制台里有「登录」按钮（网页版终端，不用装软件） |

- 如果镜像里带**宝塔** → 走文末【宝塔路线】，鼠标点几下即可。
- 如果是 Ubuntu / CentOS → 走下面的【命令行路线】。
- 如果是 Windows Server → 告诉我，我另给一份步骤。

---

## 第 1 步：把服务器 IP 加进数据库白名单（不做就连不上库）

MongoDB Atlas 只允许白名单里的 IP 访问，必须先把服务器 IP 加进去：

1. 浏览器打开 <https://cloud.mongodb.com> 登录（账号是你注册 Atlas 用的邮箱/手机号）
2. 左侧 **Network Access**（网络访问）→ **Add IP Address**
3. 填刚才记下的服务器公网 IP，备注写「生产服务器」，确认
4. 等待状态变 Active（约 1 分钟）

> 顺手看一眼：Database Access 里确认 `13589536015_db_user` 这个用户还在、密码没变。

---

## 第 2 步：域名解析到服务器

到你的域名注册商 / 腾讯云 DNSPod 控制台 → 解析设置，加两条 A 记录：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `@` | A | 服务器公网 IP |
| `www` | A | 服务器公网 IP |

生效约 1~10 分钟。验证：本地命令行执行 `ping 你的域名`，返回的 IP 是服务器的就对了。

---

## 第 3 步：服务器放行端口（安全组 / 防火墙）

在腾讯云控制台 → 防火墙（或安全组）里确认放行：`22`、`80`、`443`。
**不要把 27017 放行到公网**（数据库在 Atlas，服务器本就不开这个端口）。

---

## 第 4 步：上传代码并启动（命令行路线）

腾讯云控制台点「登录」，进网页终端，逐条执行（把仓库地址和域名换成你自己的）：

在服务器网页终端里逐段复制执行（账号是 root）：

```bash
# ---- ① 装环境（Ubuntu / Debian 复制这段）----
apt-get update -y
apt-get install -y curl git nginx
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt-get install -y nodejs
npm install -g pm2

# ---- ① 装环境（CentOS / Rocky 用这段代替上面）----
# yum install -y curl git nginx
# curl -fsSL https://rpm.nodesource.com/setup_18.x | bash -
# yum install -y nodejs
# npm install -g pm2

# ---- ② 拉代码 ----
git clone https://github.com/zmalqo1379/dingheng-canyin.git /opt/dingheng
# 若仓库是私有的，改用（TOKEN 换成 GitHub 个人访问令牌）：
# git clone https://TOKEN@github.com/zmalqo1379/dingheng-canyin.git /opt/dingheng

# ---- ③ 装依赖 ----
cd /opt/dingheng && npm install --omit=dev

# ---- ④ 建配置文件（把 deploy/生产环境.env模板.txt 内容整段粘进来）----
nano /opt/dingheng/.env      # 粘贴后按 Ctrl+O 回车保存，Ctrl+X 退出
chmod 600 /opt/dingheng/.env

# ---- ⑤ 启动服务 + 开机自启 ----
pm2 start deploy/ecosystem.config.js
pm2 save && pm2 startup

# ---- ⑥ 配置 Nginx 转发 ----
sed -i 's/your-domain.com/你的域名.com/g' /opt/dingheng/deploy/nginx-dingheng.conf
cp /opt/dingheng/deploy/nginx-dingheng.conf /etc/nginx/conf.d/dingheng.conf
rm -f /etc/nginx/conf.d/default.conf
nginx -t && systemctl enable nginx && systemctl restart nginx
```

> 上面的 `.env` 模板文件在本地 `deploy/生产环境.env模板.txt`（含真实密钥，已设为不上传 GitHub），
> 你打开它复制内容，粘贴到服务器终端即可。

### 创建环境变量文件（必做）

```bash
cat > /opt/dingheng/.env <<'EOF'
（把 deploy/生产环境.env模板.txt 的内容整段粘进来，填好 JWT_SECRET 和强密码）
EOF
chmod 600 /opt/dingheng/.env
pm2 restart dingheng
```

生成新密钥：本地命令行执行
`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

### 自检

```bash
pm2 status                 # 状态应为 online
pm2 logs dingheng --lines 50   # 看到「MongoDB 已连接」和「服务器已启动」即成功
curl http://127.0.0.1:3000     # 能返回页面 HTML 即正常
```

## 第 5 步：开 HTTPS（免费证书）

```bash
# Ubuntu
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名.com -d www.你的域名.com
# 证书 90 天自动续期，certbot 已配好定时任务，不用管
```

或走腾讯云：SSL 证书控制台 → 申请免费证书（TrustAsia，1 年）→ 下载 Nginx 版 →
放到服务器后改 `deploy/nginx-dingheng.conf` 加 443 监听段。

---

## 第 6 步：上线前必做的 5 件安全事

1. **开发者后台换强密码**：`.env` 里 `DEV_ADMIN_PASSWORD` 改成 12 位以上强密码，改完 `pm2 restart dingheng`。
2. **调试入口不外传**：`/dev-console.html` 是内部后台，**不要把地址给供应商**；平时用不到可直接在服务器删掉：`rm /opt/dingheng/public/dev-console.html`。
3. **网站底部挂备案号**：法律要求，备案号「鲁ICP备2026055131号」+ 链接 <https://beian.miit.gov.cn>。
4. **备份**：Atlas 控制台 → Clusters → 开启免费自动备份（免费层默认有快照）；`/opt/dingheng/uploads` 的图片每月手动打包下载一次。
5. **高德地图白名单**：高德控制台把正式域名加进 Key 的白名单，否则门店地图选点会失效。

## 宝塔路线（如果服务器镜像是宝塔）

1. 浏览器打开 `http://服务器IP:8888` 登录宝塔（初始账号密码在腾讯云「应用管理」里看）
2. 软件商店装：**PM2管理器**、**Nginx**（首次进宝塔会推荐装 LNMP，装 Nginx 即可）
3. 网站 → 添加站点 → 域名填你的域名 → 根目录 `/opt/dingheng/public` 之外**不用建站**，改用「反向代理」：
   站点设置 → 反向代理 → 目标 URL `http://127.0.0.1:3000`
4. 文件 → 上传项目 zip 到 `/opt/dingheng` 并解压
5. 终端 → 执行 `cd /opt/dingheng && npm install --omit=dev`
6. PM2管理器 → 添加项目：启动文件 `server.js`、项目目录 `/opt/dingheng`、端口 3000
7. 站点设置 → SSL → Let's Encrypt → 申请并开启强制 HTTPS

## 常见故障速查

| 现象 | 原因 / 处理 |
|---|---|
| 页面打不开、超时 | 服务器防火墙没放行 80/443 |
| 报「MongoDB 连接失败」 | Atlas 白名单没加服务器 IP，或没生效 |
| 能打开但图片不显示 | `uploads` 目录没随代码上传，或权限不足：`chmod -R 755 /opt/dingheng/uploads` |
| 登录后立刻掉线 | `.env` 换了 `JWT_SECRET` 属正常，让用户重新登录即可 |
| 502 Bad Gateway | Node 没起来：`pm2 logs dingheng` 看报错 |
