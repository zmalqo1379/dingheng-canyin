隐私协议

更新日期：2026年9月2日

鼎恒餐饮·智能餐饮管理平台（以下简称"本平台"）非常重视用户隐私保护。本隐私协议旨在说明我们如何收集、使用、存储和保护您的个人信息。请您在使用本平台服务前，仔细阅读并充分理解本协议的全部内容。一旦您开始使用本平台服务，即视为您已同意本协议所述的各项条款。

一、信息收集

1. 商家注册信息：当您以商家身份注册时，我们会收集您的店铺名称、联系人姓名、手机号及登录密码。手机号将作为您的登录账号并用于身份验证。

2. 供应商注册信息：当您以供应商身份注册时，我们会收集供应商名称、联系人、手机号、登录密码及主营品类信息。

3. 经营数据：包括您通过本平台创建的菜品、桌台、订单、采购单、会员积分及营业额等业务数据。

4. 设备与日志信息：在您访问本平台时，我们可能自动收集设备类型、访问时间、操作日志等用于系统安全与故障排查的信息。

二、信息使用

1. 提供服务：使用所收集的信息为您提供扫码点餐、后厨接单、供应链采购、数据统计等核心功能。

2. 身份验证与安全：通过手机号与密码验证您的身份，保障账户安全，防止未授权访问。

3. 业务通知：在您开启通知功能后，通过站内弹窗、短信或语音等方式向您推送新订单、采购状态等业务提醒。

4. 服务改进：对经营数据进行统计分析，用于优化平台功能、提升服务体验。我们仅使用脱敏后的汇总数据进行整体分析，不会针对单个商家进行不当画像。

三、信息保护

1. 密码加密：您的登录密码采用 bcrypt 不可逆加密算法存储，平台任何人员均无法获取您的明文密码。

2. 访问控制：平台采用 JWT Token 鉴权机制，所有接口均进行身份校验，开发者控制台等敏感功能需额外授权才能访问。

3. 传输安全：平台建议在 HTTPS 环境下部署运行，以保障数据在网络传输过程中的安全性。

4. 内部管理：平台对内部人员访问用户数据实行严格的权限管控与审计，禁止任何人未授权查看或泄露用户信息。

四、Cookies 及本地存储

本平台在浏览器端使用 localStorage 存储您的登录凭证（如 merchantToken、supplierToken、devToken），以便在您下次访问时保持登录状态。这些数据仅保存在您的本地设备中，不会上传至服务器。您可通过浏览器设置随时清除本地存储数据，清除后需重新登录。

五、用户权利

1. 访问与更正：您可随时登录账户查看并修改您的店铺信息、联系人信息及通知设置。

2. 账户注销：如您需注销账户或删除相关数据，可联系平台开发者协助处理。注销后您的个人信息将从活跃数据库中删除。

3. 数据导出：您有权要求导出与您相关的经营数据，平台将在合理期限内提供。

4. 权限撤回：您可随时在通知设置中关闭弹窗、短信或语音提醒等权限。

六、信息共享与披露

除以下情形外，平台不会向任何第三方共享您的个人信息：经您事先同意；为完成采购订单等业务流转，向对应的供应商披露必要的订单信息；根据法律法规要求或行政、司法机关的合法命令；为保护平台、用户或公众的合法权益所必需。

七、协议更新

本平台可能根据业务发展或法律法规变化对本协议进行修订，修订后的协议将在平台公布并自公布之日起生效。若您在协议修订后继续使用本平台服务，即视为您接受修订后的协议。

八、联系我们

如您对本隐私协议有任何疑问、意见或建议，可通过平台开发者控制台的反馈渠道与我们取得联系。我们将及时回应您的诉求。
